# Языки

**Код:** `src/i18n/`

Сейчас игра на английском и русском. Языков будет много, поэтому всё
устроено так, чтобы новый добавлялся одним файлом.

- Весь текст игры лежит в каталогах, по файлу на язык: `en.ts`, `ru.ts`.
  В коде нет ни одной фразы — только ссылки вида `t().menu.play`.
- Английский — образец. Его структуру повторяет каждый язык, а проверка
  типов не даст забыть строку. Тест сверяет, что во всех языках есть все
  строки и одинаковые подстановки (`{dmg}`, `{place}`…).
- Язык загружается, только когда его выбрали. Свои шрифты он приносит сам:
  в Fraunces и Lato нет кириллицы, поэтому русский подключает Lora и PT Sans.
- Грамматику решает перевод, а не код: у каждого зверя в бою свои фразы,
  чтобы любой язык мог склонять имена как надо; списки («a, b и c»)
  собирает браузер по правилам языка.

**Как добавить язык:** скопировать `ru.ts` в `<код>.ts`, перевести, добавить
строчку в `LANGS` в `src/i18n/index.ts` (название языка на нём самом и,
если нужно, шрифты).
