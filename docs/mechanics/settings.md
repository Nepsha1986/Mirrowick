# Настройки

**Код:** `src/ui/Settings.ts`

Кнопка **Settings** в главном меню:

- [язык](languages.md): список всех языков игры. Сначала берётся язык
  браузера, выбор запоминается;
- громкость музыки и громкость [звуков](sound.md);
- полноэкранный режим;
- удаление сохранения (два клика, чтобы не стереть случайно).
