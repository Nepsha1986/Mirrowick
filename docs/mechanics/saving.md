# Сохранение

**Код:** `src/lantern/save.ts`

- Игра сохраняется сама: раз в несколько секунд, при выходе в меню, при
  закрытии вкладки и после перехода между мирами.
- Сохраняется: мир, где стоит герой, день, время суток, что включено.
- Хранится в браузере игрока.
- В меню: **Continue** — продолжить, **New game** — начать заново.
