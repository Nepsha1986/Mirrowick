# Суть игры

**Mirrowick** — веб-игра с видом сверху о двух параллельных мирах.

- **Нижний мир** — сумрак. Ты один, с фонарём. Деревню Mirrowick от тьмы
  защищает Wick — огромная свеча на площади.
- **Верхний мир** — обычный современный мир. Здесь будут встречаться игроки, и
  отсюда игра будет работать с интернетом через сторонние сервисы.
- **Главная фишка** — переход между мирами через зеркало.
