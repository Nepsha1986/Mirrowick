# Компьютер с поиском

**Мир:** верхний, [дом](../locations/home.md) (компьютерный стол в гостиной
уже стоит)

Садишься за компьютер — открывается интерфейс с поиском в интернете.

- Встроить настоящий Google нельзя: сайты запрещают показывать себя внутри
  чужой страницы. Поиск — через API.
- API поисковиков платные, ключ нельзя держать в коде игры — нужен маленький
  сервер-посредник.
