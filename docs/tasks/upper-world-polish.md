# Доработать верхний мир

**Мир:** верхний, [дом](../locations/home.md)

- Внутренние стены дома тоньше, внешние — тоже тоньше, чем сейчас.
- Поправить забор.
- Дорога не как трасса, а грунтовая, из гравия.
- Всё с логичными неровностями: машина стоит чуть под углом, где-то нет
  гравия, крыша не идеальная, забор не ровный.
