# Книжный шкаф с покемонами

**Мир:** верхний, [дом](../locations/home.md)

Подходишь к шкафу, выбираешь книгу «Покемоны» — открывается страница о
покемоне со спрайтом. Данные берём из [PokeAPI](https://pokeapi.co).

- PokeAPI бесплатный, без ключа, работает прямо из браузера.
- Ответы кешировать.
- Пока идёт запрос — «листание страниц»; без сети — запасной текст.
