# Задачи

Что хотим сделать. Одна задача — один файл. Файл можно дописывать и
уточнять, пока не скажем «делай».

**Когда задача сделана:**

1. Файл задачи удаляем.
2. Обновляем документацию: локации, персонажей, механики, `worlds.md`, а если
   было решение — `decisions.md`.
3. Пишем коротко. Документация в первую очередь для человека.
