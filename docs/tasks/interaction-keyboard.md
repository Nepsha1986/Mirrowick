# Взаимодействие только с клавиатуры

Сейчас предмет срабатывает и по `E`, и по клику: кликнул издалека — герой
дойдёт и сам его включит. Так не нравится.

- Предметы, зеркала и люки включаются только по `E`, когда герой рядом и
  у предмета ореол.
- Клик по предмету больше ничего не включает: герой просто идёт к нему,
  как по клику на землю.
- Ходьба по клику и бой по клику (клик по зверю) остаются.
- Мобильные не поддерживаем, тач не нужен.

См. [взаимодействие](../mechanics/interaction.md).
