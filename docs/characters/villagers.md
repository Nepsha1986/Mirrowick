# Жители деревни

**Мир:** нижний · **Код:** `src/lantern/town.ts`, `LanternScene.ts`

Четверо безымянных жителей [деревни](../locations/mirrowick.md): шали разных
цветов, у некоторых корзины. Бродят между любимыми местами на улицах и
площади, постоят — идут дальше. С героем пока не взаимодействуют.

Рядом в загоне бродят и клюют куры.
