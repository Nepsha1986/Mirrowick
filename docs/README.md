# Документация Mirrowick

Здесь живёт всё, что нужно помнить об игре: о чём она, как устроены миры, что
и почему мы решили, какие идеи ждут своего часа. Код описан в корневом
[README](../README.md), а договорённости для ИИ-помощника лежат в
[CLAUDE.md](../CLAUDE.md).

| Файл                         | Что внутри                                                    |
| ---------------------------- | ------------------------------------------------------------- |
| [vision.md](vision.md)       | Суть игры в одной странице и её «столпы»                      |
| [worlds.md](worlds.md)       | Верхний и нижний мир, переход между ними: что уже есть в игре |
| [lore.md](lore.md)           | Мир, места, названия, правила вселенной; открытые вопросы     |
| [decisions.md](decisions.md) | Журнал решений: дата, что решили, почему, что отвергли        |
| [ideas.md](ideas.md)         | Парковка идей: всё, что придумали, но пока не делаем          |
| [roadmap.md](roadmap.md)     | Что сделано, что дальше, какие вопросы надо решить            |

## Как вести

- **Решили что-то важное** → строчка в `decisions.md`, даже если коротко.
- **Пришла идея, но не сейчас** → в `ideas.md`, чтобы не потерялась.
- **Сделали фичу** → обновить `worlds.md` или `roadmap.md` в том же PR.
- **Придумали что-то о мире** (название, историю, правило) → в `lore.md`.

Документ, который описывает уже сделанное, должен совпадать с игрой. Если
что-то поменялось в коде — поменяй и здесь.
