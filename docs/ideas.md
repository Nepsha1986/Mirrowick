переносим в [roadmap.md](roadmap.md), а решение записываем в

## Верхний мир и интернет

- **Книжный шкаф с покемонами.** Подходишь к шкафу, выбираешь книгу «Покемоны»,
  игра запрашивает [PokeAPI](https://pokeapi.co) и показывает страницу о
  покемоне со спрайтом.
  - PokeAPI бесплатный, без ключа, работает прямо из браузера (CORS), спрайты
    можно грузить в Phaser как текстуры.
  - Просят кешировать: прочитал один раз — сохранил.
  - Нужны «листание страниц» на время запроса и запасной текст, если сети нет.
  - Покемоны — бренд Nintendo: для прототипа нормально, для выпуска заменить.
- **Компьютер в гостиной** (стол уже стоит) открывает интерфейс с
  поиском. Поиск — через API поисковиков, они платные; нужен сервер-посредник
  для ключа.
- **Другие открытые источники:**
  - Open Library — настоящие книги в библиотеке;
  - Wikipedia — статьи-«энциклопедии»;
  - реальная погода игрока — дождь в игре, когда у него идёт дождь;
  - NASA — настоящее звёздное небо;
  - новости на доске объявлений.
- **Заказы и покупки** «у торговца на рынке». На старте — только ссылка на
  внешний магазин, без своих платежей.
- **Телевизор** в гостиной тоже может что-то показывать.

## Мультиплеер (в последнюю очередь)

- Город в верхнем мире, где встречаются игроки: магазины, прогулки, общение с
  друзьями, мини-игры.
- Сначала самое простое: видеть других игроков и чат.
- Готовые серверы реального времени: Colyseus, Nakama.
- Нужны модерация чата (в веб-играх много детей), аккаунты, хостинг.
- Город должен быть живым и без игроков: NPC, события, мини-игры.
- Ориентир: Gather.town — общение, привязанное к месту.
- Делать что-то **вместе**: читать, смотреть, ходить по магазинам.

## Нижний мир

- Подземелья, пещеры, «сны» — отдельные места с жёстким переходом.
- Связь миров через игру: книга наверху даёт подсказку для нижнего мира.
- Увеличить карту в 2–3 раза (200×160 или 300×250), когда появится чем
  её заполнить.

## Мир в целом

- Правило «отражения наоборот» (как мельница) применить и к другим местам.
- Офлайн-режим: нижний мир работает без интернета, верхнему нужна сеть — это
  можно сделать частью лора.
