### 2026-10-17 · Документация живёт в репозитории

**Решили:** вести документацию в папке `docs/` в Markdown-файлах, рядом с
кодом; памятка для ИИ — в `CLAUDE.md`.
**Почему:** решения забываются, а ИИ-помощник не помнит прошлые сессии.
Документы обновляются в тех же PR, что и код, и читаются с GitHub.

### 2026-10-17 · Свой характер музыки у каждого мира

**Решили:** внизу — ре минор, гул, далёкие колокола; наверху — фа мажор,
открытый звук, музыкальная шкатулка. При переходе — плавная смена за пару
секунд.
**Почему:** мрачная музыка не подходит обычному солнечному миру; контраст
миров должен быть слышен, а не только виден.

### 2026-10-16 · Мельница и зеркало — переход между мирами

**Решили:**

- Верхний мир для начала — один дом с участком (40×30 клеток).
- На обеих картах стоит мельница: наверху **разрушенная**, внизу **целая**.
- Переход — зеркало из чёрного стекла в полу мельницы. `E` или клик.
- Новая игра начинается наверху, дома. Главное меню показывает нижний мир.
- Время суток при переходе сохраняется.

**Почему:** переход должен быть событием и частью мира, а не кнопкой. Мельница,
отражённая «наоборот», сама рассказывает о связи миров. Чёрное стекло
связывает переход с Зеркалом нижнего мира.

### 2026-10-16 · Бесшовный конечный мир, жёсткие переходы только на порогах

**Решили:** внутри одного мира — бесшовное пространство, без экранов. Здания —
тоже без переходов (крыша растворяется). Жёсткий переход с эффектом — только
там, где он что-то значит: зеркало между мирами, в будущем — подземелья.
**Отвергли:**

- _переход «с экрана на экран»_ — разрывает погружение, а атмосфера фонаря
  держится на ощущении мира вокруг;
- _бесконечный процедурный мир_ — в игре с историей он быстро становится пустым
  и однообразным.

### 2026-10-16 · Размер карты пока не увеличиваем

**Решили:** нижний мир остаётся 100×80 клеток.
**Что выяснили:** без переделок движок потянет до ~500×400 клеток (в 25 раз
больше, ~2 минуты пешком насквозь). Объекты уже показываются кусками (чанками),
землю Phaser рисует только в пределах экрана. При ~1000×1000 понадобится
подгружать землю кусками. Главный предел не техника, а наполнение: большой мир
нужно чем-то заполнить. Разумный следующий шаг, когда понадобится, — 200×160
или 300×250.

### 2026-10-16 · Два мира: одинокий нижний и людный верхний

**Решили:** главная фишка игры — переход между мирами. Нижний мир — сумрак,
игра в одиночку. Верхний мир — обычный город, где встречаются игроки, и где
игра взаимодействует с интернетом.
**Порядок разработки** (рекомендация, принята как ориентир):

1. Нижний мир — сердце игры: должно быть интересно играть одному.
2. Верхний мир без мультиплеера: место, NPC, связь с внешними API.
3. Переход через зеркало как событие. _(сделано)_
4. Мультиплеер — в последнюю очередь, начиная с простого (видеть других, чат).

**Почему такой порядок:** мультиплеер — самая дорогая часть (сервер, аккаунты,
модерация чата, хостинг), а пустой мультиплеерный город выглядит мёртвым. Город
должен быть живым и без других игроков.

### 2026-10-16 · Интернет в игре — через API, а не через «встроенный браузер»

**Решили:** внешние сервисы показываем так: берём данные по API и рисуем их в
стиле игры (книга на полке, экран компьютера, доска объявлений).
**Почему:** большинство сайтов (Google, YouTube, магазины) запрещают показывать
себя внутри чужой страницы. Ключи платных API нельзя хранить в коде игры —
для них понадобится маленький сервер-посредник. Настоящие покупки — платежи и
ответственность: на старте только ссылки на внешний магазин.
**Важно для дизайна:** связь с интернетом должна давать то, чего нет в обычном
браузере: делать вместе с другими, получать награду, находить подсказки для
нижнего мира. Иначе это фокус на один раз.

### 2026-10-16 · Стиль «фонаря»; всё нарисовано кодом

**Решили:** из всех прототипов остаётся «фонарь» (по мотивам игры Заслон):
вид сверху, свободное движение, настоящая темнота с пятном и лучом фонаря,
смена дня и ночи. Все текстуры рисуются кодом в canvas при запуске, музыка
синтезируется Web Audio. Файлов картинок и звуков нет.
**Отвергли:**

- изометрию в духе Fallout (первый прототип);
- вид сверху на пиксельной графике Kenney из Tiled-карты;
- первый «нарисованный» вариант с настраиваемыми настроениями.

Их код и ассеты удалены.

### 2026-10-16 · Технологии

**Решили:** Phaser 4 (WebGL), TypeScript, Vite; ESLint, Prettier, Vitest. CI
на GitHub Actions проверяет линт, форматирование, тесты и сборку, а `main`
публикуется на GitHub Pages.
**Почему:** игра должна запускаться в браузере по ссылке — это и удобно, и даёт
естественный доступ к интернету и API.
