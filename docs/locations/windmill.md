# Мельница

**Мир:** оба · **Код:** `src/lantern/mill.ts`, `world.ts`, `upper.ts`

Одна и та же мельница в двух мирах — и через неё миры соединены.

|                | Нижний мир                                 | Верхний мир                                                 |
| -------------- | ------------------------------------------ | ----------------------------------------------------------- |
| Где            | Холм к северо-востоку от деревни           | Выше по тропе от дома                                       |
| Состояние      | **Целая**: конусная крыша, крылья крутятся | **Руина**: стены осыпались, крыши нет, крылья лежат в траве |
| Внутри         | Жёрнов, мешки с мукой, бочка               | Расколотый жёрнов, обломки                                  |
| Зеркало в полу | Целое                                      | Треснувшее                                                  |

Зеркало в полу ведёт в другой мир — см. [переход](../mechanics/mirror-travel.md).
