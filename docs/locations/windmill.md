# Мельница

**Мир:** нижний и верхний · **Код:** `src/lantern/mill.ts`, `world.ts`, `upper.ts`

Одна и та же мельница в двух мирах. Круглая каменная башня.

|           | Нижний мир                                 | Верхний мир                                                |
| --------- | ------------------------------------------ | ---------------------------------------------------------- |
| Где       | Холм к северо-востоку от деревни           | Выше по тропе от дома                                      |
| Состояние | **Целая**: конусная крыша, крылья крутятся | **Руина**: стена в проломах, крыши нет, крылья в траве     |
| Пол       | Доски                                      | Разбитые плиты, сквозь них трава                           |
| Внутри    | Жёрнов, мешки с мукой, бочка, **зеркало**  | Расколотый жёрнов, **люк в [подвал](cellar.md)**, на замке |

См. [переход между мирами](../mechanics/mirror-travel.md).
